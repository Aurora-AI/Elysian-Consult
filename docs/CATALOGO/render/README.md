## Por que o SSOT já está aqui

Porque o destino define a disciplina. Deixá-lo em `SSOT/` mantinha a tentação de
continuar editando à mão, e cada edição manual reabre o problema que o registro
existe para fechar: três documentos com três vetores de peso diferentes.
